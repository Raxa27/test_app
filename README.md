# Sawari Madadgar (Ride Helper)

Ammi/abbu ke liye ek aasan web app jo **Yango** ya **inDrive** par ride book karne mein qadam ba qadam madad karti hai.

## Kya karti hai
- **Bade buttons** wali saved jagahein (Ghar, Doctor, Masjid…): ek tap mein chunein.
- **Urdu (اردو) aur Roman Urdu**, upar button se badlein.
- Har app ke liye **8 aasan steps**, jo **🔊 sun bhi** sakte hain. Har step mukammal hone par tick hota hai.
- **📋 Pata copy** hota hai aur app khulti hai, phir app mein sirf Paste karna hai.
- inDrive ke liye **pehle se tay kiraya** dikhata hai.
- **🆘 Madad chahiye**: bachon ko WhatsApp par message jata hai, saath mein GPS location.
- **📞 Phone karein**: seedha bachon ko call.
- **🚗 Gaari aa gayi?**: safety checklist (number, rang, driver) aur "gaari mein baith gaya" ka message.

## Setup kaise karein (bachon ke liye)
1. `index.html` ko kahin host karein (jaise GitHub Pages: Settings → Pages → branch chunein).
2. Link kholein → neeche **⚙️ Setup** → apna naam, WhatsApp number (92300…) aur jagahein dalein.
3. **📤 Ye setup ammi/abbu ko bhejein** dabayein → WhatsApp par link jayega.
4. Ammi/abbu link kholein → saari jagahein unke phone mein save ho jati hain. Phir link ko "Add to Home screen" kar dein.

Saara data sirf phone mein (localStorage) rehta hai, kisi server par nahi jata.

## Note
Android par "App kholein" button app ko kholta hai, aur agar app install nahi to Play Store par le jata hai. Destination khud app mein nahi bharta, isliye pata copy hota hai aur Paste karna hota hai.
